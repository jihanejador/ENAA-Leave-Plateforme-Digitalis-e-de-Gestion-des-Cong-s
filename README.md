# 🚀 ENAA - Leave Management System

A full-stack web application for managing employee leave requests, built with **Laravel (API)**, **React.js (Vite)**, and containerized using **Docker & Docker Compose**.

---

## 🛠️ Tech Stack

* **Backend:** PHP 8.3 (Laravel API)
* **Frontend:** React.js (Vite + Tailwind CSS)
* **Database:** MySQL 8.0
* **Web Server:** Nginx
* **Containerization:** Docker & Docker Compose
